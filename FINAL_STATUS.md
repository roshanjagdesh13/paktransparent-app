## 🚀 Quick Start Commands

### 1. Create Flutter Project
```bash
cd "C:\Users\Roshan\OneDrive\Desktop\budget tracker"
flutter create paktransparent_flutter
cd paktransparent_flutter
```

### 2. Add Dependencies
```yaml
# pubspec.yaml
dependencies:
  provider: ^6.1.1              # State management
  http: ^1.1.0                  # Networking
  flutter_secure_storage: ^9.0.0  # Secure storage
  shared_preferences: ^2.2.2    # Local storage
  image_picker: ^1.0.5          # Image handling
  file_picker: ^6.1.1           # File handling
  crypto: ^3.0.3                # Security
  intl: ^0.18.1                 # Internationalization
  qr_code_scanner: ^1.0.1       # QR scanning
  fl_chart: ^0.65.0             # Charts
  google_maps_flutter: ^2.5.0   # Maps
```

### 3. Create Folder Structure
```bash
mkdir lib/core lib/data lib/presentation
mkdir lib/core/theme lib/core/utils lib/core/constants
mkdir lib/data/models lib/data/services lib/data/repositories
mkdir lib/presentation/screens lib/presentation/widgets lib/presentation/providers
```
