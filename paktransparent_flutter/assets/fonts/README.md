# Urdu Fonts Required

This app requires Noto Nastaliq Urdu fonts for proper Urdu text rendering.

## Download Fonts

Download the following fonts from Google Fonts:
https://fonts.google.com/noto/specimen/Noto+Nastaliq+Urdu

Required files:
- NotoNastaliqUrdu-Regular.ttf
- NotoNastaliqUrdu-Bold.ttf

## Installation

1. Download the font files
2. Place them in this directory (`assets/fonts/`)
3. Run `flutter pub get` to update assets

## Alternative

If you don't need Urdu support immediately, you can comment out the fonts section in `pubspec.yaml` temporarily.
